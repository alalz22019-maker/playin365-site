# PlayIn365 — Golden Training Day

## القرار

يوم التدريب هو أول رحلة تشغيلية كاملة فوق ركائز PlayIn365 الثلاث:

1. **الأفراد:** اللاعب، المدرب، الإداري، المالك وولي الأمر.
2. **الجهات:** الأكاديمية والفريق والفرع.
3. **الأحداث:** الحصة التدريبية كسجل مستقل يربط الأطراف والخطة والحضور والجاهزية والتقييم والأثر.

لا تحذف الرحلة أي خدمة قديمة. المسارات السابقة تبقى متاحة، بينما تصبح `trainingDay` نقطة التجميع اليومية للحصة.

## الرحلة من البداية إلى النهاية

```text
الأكاديمية تنشئ الحصة وتحدد الفريق والمدرب والمكان
→ المدرب يبني مراحل الخطة وينشرها
→ اللاعب يستلم الخطة ويؤكد الحضور
→ اللاعب يحدث جاهزيته مع حماية التفاصيل الحساسة
→ المدرب والأكاديمية يريان مؤشر الجاهزية فقط
→ المدرب يسجل الحضور والدقائق والحمل المدرك
→ المدرب ينشر تقييمًا منظمًا للاعب
→ تُغلق الحصة
→ يتحول التقييم إلى Assessment معتمد
→ تتحدث Performance Metrics وهوية الحدث والخط الزمني للاعب والجهة
```

لا تعتمد الرحلة التشغيلية على اسم اللاعب أو `localStorage` كمفتاح أو مصدر حقيقة.

## تجربة كل دور

### الأكاديمية

- إنشاء الحصة وربطها بالفريق والمدرب.
- رؤية التأكيدات والجاهزية المجمعة والحضور والتقييمات.
- تشغيل الحصة وإغلاقها وتوثيق أثرها.
- الوصول إلى هوية الحدث.

### المدرب

- بناء خطة الحصة من مراحل ومدد وأهداف وشدة.
- نشر الخطة للاعبين.
- رؤية جاهزية الفريق دون كشف الملاحظات الخاصة.
- تسجيل الحضور والدقائق وRPE.
- تقييم اللاعب فنيًا وتكتيكيًا وبدنيًا وذهنيًا.
- إغلاق الحصة وتحديث السجلات.

### اللاعب

- رؤية الموعد والمكان والخطة المنشورة.
- تأكيد الحضور أو الاعتذار.
- تحديث النوم والإجهاد والطاقة والألم.
- الاحتفاظ بالملاحظة الخاصة دون عرضها للمدرب أو الأكاديمية.
- رؤية تقييم المدرب المصرح بعد الإغلاق.
- ظهور أثر الحصة في سجله الرياضي.

## الخصوصية والصلاحيات

- اللاعب لا يرى جاهزية أو حضور أو تقييم زملائه.
- المدرب والجهة لا يريان الملاحظة الخاصة للاعب.
- اللاعب لا يستطيع تسجيل الحضور أو تقييم نفسه.
- المدرب المعين أو المسؤول المخول فقط يستطيع إدارة الحصة.
- إغلاق الحصة يمنع التعديل غير المقصود ويصدر أثرًا موثقًا.

## النظام البصري

تستخدم الرحلة **PlayIn Live Canvas** بدل شبكة صناديق تقليدية:

- Scene للحصة.
- Timeline لمراحل الخطة.
- Field Map لجاهزية الفريق.
- Live Roster للحضور والتقييم.
- Context Sheets للإجراءات المركزة.
- Smart Home Signal لإظهار الخطوة المطلوبة دون فتح الصفحات الفرعية.

الشكل الهندسي مأخوذ من مسار SVG المعتمد نفسه دون إعادة رسم:

- الأكاديمية `TL`
- المدرب `BL`
- اللاعب `BR`
